# Installation

Install with Homebridge UI or `npm install -g homebridge-persistent-alarm`. Requires Homebridge `^1.6.0 || ^2.0.0` and Node.js `^22.12.0 || ^24.0.0 || ^26.0.0`. Node.js 26 requires Homebridge 2.5.0 or later.
